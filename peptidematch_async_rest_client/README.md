#  PeptideMatchAsyncRESTClient project

This project is a Java based asynchronous client, which can be used to test the asynchronous RESTful API of Peptide Match service.

**Legacy:** this client was written for the original Solr-based service. For the current Elasticsearch-based service, use [peptidematch_async_rest_client_es](../peptidematch_async_rest_client_es/).
